# 🚀 Mahmoud — Developer Portfolio

A modern, responsive developer portfolio built to showcase my skills, projects, experience, and contact information.

The portfolio combines a clean developer-focused interface with a futuristic **HUD / gaming-inspired visual style**, using a dark interface, green accents, subtle glow effects, and smooth animations.

---

* 🎨 Modern futuristic UI
* 🌙 Dark-themed interface
* 📱 Fully responsive design
* 🧑‍💻 About Me section
* ⚡ Skills & technologies showcase
* 🚀 Projects showcase
* 📩 Contact section
* 🧭 Client-side navigation
* ✨ Smooth hover and entrance animations

* ♿ Accessible and semantic UI

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

You can verify your installation with:

```bash
node -v
npm -v
```

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to the project directory:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal.

---

## 🏗️ Build for Production

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🎨 Design

The portfolio follows a futuristic developer / HUD-inspired design system.

### Visual direction

* Dark background
* Green primary accent
* High-contrast typography
* Minimal borders
* Subtle glowing effects
* Futuristic interface elements
* Responsive layouts
* Smooth micro-interactions

The goal is to create a portfolio that feels more like a **developer interface** than a traditional portfolio website.
